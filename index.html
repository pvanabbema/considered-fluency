My AI Fluency Plan

By the gate date, I can delegate, describe, discern, and be diligent with AI on my real work: I choose the right tasks, specify them precisely, judge the output, and own the result.

Default plan: 35 sessions · ~35 hours · six sprints. This file is yours: set it up in the panel below, no code needed. Progress is stored only in your browser.

Make this yours — no code required

  1. Fill in the three fields above and save. Title, objective, and gate apply immediately and are remembered by your browser; the file itself is untouched.
  2. Work the cadence. Tick sessions as you complete them; review the Measures table weekly; keep the pace counter honest.
  3. Optional, for the comfortable: the plan is plain HTML. Open it in a text editor to prune or add sessions (each is a small block with a unique data-id and an data-h hours value); counters recalculate automatically.
Where does my data go?

Nowhere. This page makes zero network requests. Completion state lives in your browser's local storage under the key named on the <body> tag. Clearing site data clears progress, so use the export button to keep a copy. Moving to a new machine: export, then keep the JSON with the file.

Six sprints

The plan is structured on the four AI fluency competencies — Delegation (deciding whether, when and how to engage AI), Description (specifying goals precisely), Discernment (judging output quality), and Diligence (owning the result) — then applies them to one real project and closes with evidence. Sessions bind to competencies, not to any vendor's tool, so the plan survives tool churn.
